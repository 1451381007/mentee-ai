# 面试模拟与分析系统

这是一个基于 React 和 TypeScript 开发的面试模拟与分析系统，帮助用户进行面试练习和能力提升。

## 功能特点

- 项目管理：创建和管理多个面试项目
- 面试模拟：模拟真实面试场景，支持文字和语音输入
- 历史记录：保存所有面试记录
- 分析报告：生成详细的面试分析报告
- 数据可视化：直观展示面试表现和进步

## 技术栈

- React 18
- TypeScript
- Ant Design
- React Router
- LocalStorage 数据持久化

## 开始使用

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm start
```

3. 构建生产版本：
```bash
npm run build
```

## 项目结构

```
src/
  ├── components/     # 共用组件
  ├── pages/         # 页面组件
  ├── App.tsx        # 应用入口
  ├── index.tsx      # 渲染入口
  └── index.css      # 全局样式
```

## 使用说明

1. 创建项目：在首页点击"创建新项目"按钮
2. 开始模拟：进入项目详情页，点击"开始模拟面试"
3. 查看分析：面试结束后自动生成分析报告
4. 历史记录：在项目详情页查看所有历史面试记录

## 注意事项

- 请确保浏览器启用了本地存储功能
- 语音输入功能需要浏览器支持相关API
- 建议使用 Chrome 或 Firefox 最新版本
